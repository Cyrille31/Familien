    Fichier Google Sheets

    Dans Google Sheets : Partager → « Accès général » → Tous les utilisateurs disposant du lien (Lecteur), puis copiez le lien. Pour utiliser un autre onglet, ouvrez-le avant de copier le lien.

    Fichier privé : connexion Google

    Pour un fichier non public, l'application vous demande de vous connecter à votre compte Google (lecture seule). Seuls les comptes ayant accès au fichier peuvent le charger.

    Installer sur l'appareil

    • iPhone / iPad : dans Safari, bouton Partager → « Sur l'écran d'accueil ».
    • Android : dans Chrome, menu ⋮ → « Installer l'application ».
    • PC / Mac : icône d'installation à droite de la barre d'adresse (Chrome, Edge).

    Une fois installée, l'application fonctionne sans connexion : le fichier est gardé sur l'appareil.
